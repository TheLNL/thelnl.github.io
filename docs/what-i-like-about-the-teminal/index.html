What I like about the terminal

The terminal is basically a drawing surface where you are limited to a grid for layout. Everything else is just a design decision of the software that runs in the terminal, I will look at both aspects.

  1. grid makes locating easier

  2. because locating is easier padding is not required, saving screen space.

  3. Screen space is also saved by not using huge UI elements. the GUI text editor I am writing this in has a save button that would be the size of a 3x5 Terminal character grid

  4. You don’t often have to switch bw input methods like GUI often forces you to do

  5. There is the cli that allows you to combine many individual tools to craft a customized tool that makes certain tasks effortless

  6. The software found in it is often honest, informative and transparent, removing the frustration of dealing with unexpected behaviour in a GUI app and not knowing what is going on or what to do

  7. Fixed color palette makes is easy to associate certain colors with certain ideas

  8. Terminal software doesn’t hesitate to use colors to make highlight differences
